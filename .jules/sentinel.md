## 2026-10-06 - Prevent DoS via Rust Panics on Empty Collections and Unhandled Unwraps
**Vulnerability:** The application was susceptible to Denial of Service (DoS) attacks through unhandled `.unwrap()` calls and array length calculations across its extraction engines. If a feature processor (such as `SortProcessor` calculating the median) encountered an empty window/chunk, the unhandled boundary could trigger `select_nth_unstable_by` with a zero-length slice, or an `.unwrap()` on an empty max_by iterator, causing the Rust engine to panic and crash the Python process.
**Learning:** Rust's strict safety checks will forcefully terminate execution via panic if an unhandled invalid state is reached. Relying on `.unwrap()` or unchecked indices assumes the data will always meet prerequisite dimensions, which is not guaranteed for edge cases like zero-length arrays, disjoint boundary slices, or unresolved parameter tracking arrays (e.g., `unique_c3_lags`).
**Prevention:** Always implement explicit guard conditions for `len == 0` or missing state variables prior to slicing or calculating metrics. Replace `.unwrap()` with robust alternatives like `.unwrap_or(&0.0)` or `f32::NAN` whenever encountering potentially empty sequences, ensuring graceful error handling and uninterrupted processing at the Python boundary.
## 2026-10-06 - Prevent DoS via Rust Panics on select_nth_unstable_by in changes and min_max features
**Vulnerability:** The `MedianDiff`, `MedianAbsDiff`, and `MeanNAbsoluteMax` feature calculations could panic when calling `select_nth_unstable_by` with zero-length internal slices. Specifically, a calculation resolving to zero elements would cause the Rust standard library to panic out of bounds, which terminates the parent Python process.
**Learning:** `select_nth_unstable_by` panics if the target index is outside the bounds of the slice. For features accumulating intermediate difference variables, a dynamically empty chunk or list mapping to `len == 0` causes an implicit crash if `n_len` bounds are assumed non-zero without validation.
**Prevention:** Guard all median and quantile selection operations (like `select_nth_unstable_by`) with an explicit `len == 0` check, returning `f32::NAN` instead to prevent a hard panic and process termination.
